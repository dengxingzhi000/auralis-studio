# DSP 算法规范

## 1. 总则

每个算法必须定义输入前提、参数、单位、归一化方式、输出结构、边界行为、误差目标与测试方法。DSP crate 不依赖 UI、设备 API、文件系统或数据库。

## 2. 输入规范

- 内部 PCM 首选 `f32`，输入解码后保留源采样率。
- 明确交错声道布局，例如 L0,R0,L1,R1。
- 校验帧边界与通道数。
- NaN/Inf 的处理策略必须显式定义：拒绝、标记或清理，不允许静默传播。
- 超出 [-1, 1] 的浮点样本可合法存在于处理链中，不能默认裁剪。
- 对空输入、部分帧和长度不足返回明确结果/错误。

## 3. RMS

对于 N 个样本：

RMS = sqrt(sum(x[n]^2) / N)

必须定义统计窗口与声道聚合方式。多声道结果首选每通道分别给出，聚合值如需提供应说明规则。

- **离线分析**：逐声道计算，`peakDbfsPerChannel` / `rmsDbfsPerChannel` 一并返回。
- **实时电平**：每声道独立计算，聚合峰值取各声道最大值，聚合 RMS 取
  `sqrt(mean(rms_c²))`（能量平均，EBU R128 / BS.1770 的做法）。**不得**
  先做 mid-sum 再算电平：完全反相的立体声 L=+1、R=−1 会被混成数字静音，
  但两路实际都是满刻度。mid-sum 只用于单声道兼容的频谱显示。
- **声道布局**：交错数据按 `L0,R0,L1,R1…` 解释，帧计数以帧为单位，
  不是以样本为单位。

dBFS 转换需要明确参考值；零值使用显示下限或明确的 `-inf` 数值语义，避免 UI 非法数值。

## 4. Peak 与 DC Offset

Peak = max(abs(x[n]))。

DC Offset = sum(x[n]) / N。

同时提供每通道结果。数字样本峰值达到或超过阈值不等于能够证明模拟链路发生削波。

## 5. FFT 频谱

- 频率 bin 间隔 Δf = sample_rate / fft_size。
- 说明 FFT 输入帧长、FFT 长度、零填充和 Hop Size 的语义。
- 明确窗函数及其 coherent gain / 能量归一化。
- 对实数单边频谱正确处理 DC 和 Nyquist bin，不可统一将所有 bin 乘 2。
- 分离 amplitude spectrum、power spectrum 与 PSD。
- 频率映射为 f[k] = k * sample_rate / fft_size。
- 对数显示需定义零值下限与最小显示电平。
- 峰值插值是可选功能，必须独立测试，不能替代原始 bin 数据。

支持的窗函数：Rectangular、Hann、Hamming、Blackman、FlatTop、BlackmanHarris。
每种窗函数都有已知系数、coherent gain（CG）与 ENBW 的数值测试。

| 窗 | CG | ENBW（bin） | 最坏扇贝损失 | 适用 |
|---|---|---|---|---|
| Rectangular | 1.0 | 1.000 | 3.92 dB | 瞬态、最窄主瓣 |
| Hann | 0.5 | 1.500 | 1.42 dB | 通用默认 |
| Hamming | 0.54 | 1.363 | 1.78 dB | 旁瓣与分辨率折中 |
| Blackman | 0.42 | 1.727 | 1.10 dB | 低旁瓣 |
| FlatTop | 0.21557895 | 3.770 | ≈0.01 dB | **幅值测量**（读数不随频率偏离 bin 中心而明显下降） |
| BlackmanHarris | 0.35875 | 2.004 | 0.83 dB | 低旁瓣（≈-92 dB）且不想像 FlatTop 那样牺牲分辨率 |

> 窗函数的「最坏扇贝损失」是**未插值 bin 读数**的性质；峰值插值只能减小、
> 不能消除这个误差。需要精确幅值时优先换 FlatTop，而不是依赖插值。
> 当前 UI 尚未提供窗函数选择器；FlatTop / BlackmanHarris 已可在 DSP 配置层使用。

**峰值挑选**（文件频谱面板）：局部极大 → prominence ≥ 6 dB →
相邻已选峰间距 ≥ 2 bin → 动态范围 80 dB → 最多 8 个。
只做局部极大判定时，窗函数旁瓣与噪声起伏会产生大量假峰。

帧级调用（STFT / 实时 / 合成信号）走 `detect_peaks`，用**宽松默认值**：
不做 prominence 过滤、**不做动态范围门限**（门限值取无穷，即「关闭」）、
已选峰最小间隔 1 bin。这样逐帧行为与引入 prominence 之前完全一致——
门限一旦在默认路径上生效，帧级报出的峰就会悄悄变少。
需要过滤的调用方必须**显式**给出门限值。

### 5.1 频谱分析的输入窗口

「频谱」面板显示的是**峰值频谱**（max-hold），不是某一帧的瞬时频谱：

| 项 | 取值 |
|---|---|
| 输入 | 文件开头 30 s 的**通道 0** 样本（`SPECTRUM_WINDOW_SECONDS`） |
| FFT 长度 | 8192 |
| Hop | 4096（50% 重叠） |
| 窗 | Hann，`remove_dc = false` |
| 合并方式 | 各帧幅值谱**逐 bin 取最大值** |
| 峰值检出 | 从**合并后**的谱检出，保证与画出来的曲线一致 |
| 边界 | 样本不足一帧时**不产出频谱**（而不是给一条假曲线） |

**为什么必须用整段而不是第一帧**：8192 样本在 44.1 kHz 下只有 186 ms。
只取第一帧时，开头是静音的文件会得到一条贴底的「空」频谱——
界面上看起来就是「分析了但什么都没出来」。实测用户的 FLAC 正是这种文件
（前 100 ms 静音）。

**零填充**：不做。末尾不足一帧的样本按丢弃处理（与 §6 的边界帧策略一致），
补零会造出假的衰减。

**代价**：30 s 窗口约 320 帧。release 构建下频谱部分的中位数代价约 +90 ms
（同机同文件 A/B：单帧 273 ms vs 整段 350 ms，机器有并行构建，抖动较大）。

### 5.2 波形包络

波形面板不画原始 PCM，而是画**每声道每桶 min/max**：

| 项 | 取值 |
|---|---|
| 结构 | `waveformEnvelope`（每桶最大值）与 `waveformMin`（每桶最小值）成对出现 |
| 布局 | 声道优先：`[ch0 × points, ch1 × points, …]`；`waveformPoints` 是**每声道**点数 |
| 桶大小 | 从 1 帧开始；活跃桶数超过 `2 × points` 时相邻两桶合并并翻倍 |
| 结束 | 剩余桶合并到恰好 `points` 列；短于 `points` 帧时相邻列重复，不伪造细节 |
| 内存 | 上界约 `2 × points × 声道数 × 8 B`（2048 点立体声约 64 KB），与文件长度无关 |
| 非有限值 | 按 0 处理（与统计口径一致），不外传 NaN/Inf |

只保留最大值会丢掉负半波；保留抽样点会丢掉瞬态。两者都不允许。

## 6. STFT 与声谱图

- 定义 frame length、hop size、window 和 FFT size。
- 定义边界帧策略（丢弃、不足补零等）。
- 定义色阶输入量纲（幅值、功率或 PSD）与 dB 参考值。
- 数据生产与纹理绘制解耦。
- 对视口外时间段按需计算/加载，防止矩阵无界增长。

## 7. 削波特征

分开报告：
1. 超过数字满刻度（`|x| > 1.0`）的样本数；
2. 连续极值样本或平顶特征（启发式片段数）；
3. 诊断置信度/限制说明。

平顶检测器是**流式**的：离线解码按块喂入交错样本，每声道保留当前连续段
的状态，跨解码块的片段只计一次。参数（阈值、最短连续长度）由
`ClippingConfig` 定义，检测结果只说明「数字样本呈现平顶」，
**不是**模拟链路削波的证据。

不要仅因样本达到 0 dBFS 就断言发生模拟削波。

## 8. 高级指标门槛

SNR、THD、THD+N、频率响应、LUFS、A/C/Z 计权必须先有独立规格：
- 输入信号条件；
- 参考信号/基波识别；
- 带宽与滤波器；
- 加权标准；
- 单位与计算公式；
- 无效输入行为；
- 参考实现或黄金数据集；
- 测量误差分析。

在规格和测试通过前，不输出伪造或占位数值。

**当前状态**：LUFS / 真峰值（true peak）尚未实现。界面不显示这两个指标，
导出也不写入占位值；在 EBU R128 规格、重采样/过采样策略与黄金数据验证
完成之前，不得声称合规。

## 9. 误差目标与测试

初始工程目标（需基准验证）：
- 已知合成正弦的频率峰值落在理论频率对应 bin 或预期插值容差内。
- 对满足相干采样和校正条件的幅值测试，预设误差目标可设为 ≤ 0.2 dB。
- 全零输入不得产生 NaN/Inf。
- 直流、Nyquist、近 Nyquist 和非整数周期信号必须覆盖。
- 不同通道应隔离计算。
- 所有参考数据与测试参数必须可重复。
