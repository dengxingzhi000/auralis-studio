# UI/UX 设计规范

## 1. 视觉方向

专业测量仪器 + 现代开发者工具。深色优先、紧凑但清晰的信息密度、弱边框、明确层级，避免通用后台管理模板和过度发光效果。

## 2. 设计 Token

- `bg.app`: `#101318`
- `bg.panel`: `#181D25`
- `bg.elevated`: `#202733`
- `border.subtle`: `#303946`
- `text.primary`: `#E7EBF1`
- `text.secondary`: `#98A3B3`
- `accent.primary`: `#57A6FF`
- `signal.positive`: `#54D6A0`
- `signal.warning`: `#F2B75B`
- `signal.critical`: `#FF657A`

将 token 集中定义，禁止将颜色常量散落在所有组件中。数值使用等宽字体；重要状态不能只通过颜色表达。

## 3. 主窗口布局

- 顶部命令栏：导入、采集控制、布局、导出。
- 左侧资源栏：文件、设备、任务、历史记录。
- 中央画布：波形、频谱、声谱图、电平表、指标。
- 右侧检查器：当前分析器的参数和显示选项。
- 底部状态栏：采样率、设备状态、任务进度、丢帧、错误。
- 面板可隐藏、调整大小；优先支持常用布局。

## 4. 视图组件

- `WaveformView`：多级波形包络、时间缩放、选区。
- `SpectrumView`：频率/幅值轴、曲线、峰值标记、游标。
- `SpectrogramView`：纹理/图像绘制、色阶、时间与频率映射。
- `LevelMeter`：Peak/RMS、削波状态。
- `ChannelCompareView`：通道叠加和差异。
- `AnalysisSummaryView`：指标、单位、参数和诊断。
- `ChartToolbar`：缩放、平移、复位、截图、单位选择。

## 5. 图表性能

- `egui_plot` 用于基础二维曲线原型。
- 密集声谱图不得将每个时频单元建成独立绘图对象。
- 波形应使用 min/max 多级包络。
- 根据像素宽度对频谱数据降采样。
- UI 只读不可变快照；避免持有实时可变缓冲区锁。
- 控制纹理尺寸、缓存容量和刷新频率。

## 6. 交互规范

- 鼠标悬停显示明确数值与单位。
- 游标位置、选区和缩放行为可预测。
- 参数修改应有即时反馈，耗时计算异步运行。
- 对设备不可用、缓冲溢出、无效参数提供可操作提示。
- 常用操作提供键盘支持。
- 支持窗口缩放与高 DPI。

## 7. 视觉验收

- 在常规窗口和高 DPI 下无关键控件遮挡。
- 标签、刻度、单位清晰可读。
- 频谱坐标映射与实际数据一致。
- 大文件和实时采集时交互不被计算阻塞。
- 暂停、无信号、错误和削波状态均有明确视觉反馈。
