# UI/UX 设计规范

## 1. 视觉方向

专业测量仪器 + 现代开发者工具。深色优先、紧凑但清晰的信息密度、弱边框、明确层级，避免通用后台管理模板和过度发光效果。

## 2. 设计 Token

唯一来源：`apps/desktop/src/styles/tokens.css`。组件与 Canvas 渲染都从这里取值，
**不得在组件里写死颜色**（ADR-017）。

### 2.1 中性色阶（层级来源）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg-app` | `#0a0c0f` | 应用底色、中央画布 |
| `--bg-sidebar` | `#0e1116` | 左右侧栏、顶部/底部条 |
| `--bg-panel` | `#121519` | 卡片、面板表面、图表底 |
| `--bg-elevated` | `#191e25` | 卡片头、工具条、悬浮层 |
| `--bg-input` | `#0c0f13` | 输入框内凹底色 |
| `--bg-hover` / `--bg-active` | `#1d232b` / `#232a34` | 悬停 / 选中填充 |
| `--border-subtle` | `#272d37` | 卡片与分区描边 |
| `--border-strong` | `#333b47` | 强调分隔、输入悬停 |
| `--text-primary` | `#e9edf3` | 正文与读数 |
| `--text-secondary` | `#9aa5b4` | 标签与说明 |
| `--text-disabled` | `#5d6675` | 禁用与占位 |

### 2.2 语义色

| 令牌 | 值 | 用途 |
|---|---|---|
| `--accent-primary` / `--accent-hover` | `#57a6ff` / `#74b6ff` | 主操作、曲线、焦点 |
| `--signal-positive` | `#54d6a0` | 正常状态 |
| `--signal-warning` | `#f2b75b` | 未验证 / 估算读数 |
| `--signal-critical` | `#ff657a` | 错误 |
| `--grid-minor` / `--grid-major` / `--axis-line` | `#1a2028` / `#232a34` / `#333b47` | 图表三级网格 |

数值使用等宽字体；重要状态不能只通过颜色表达。

### 2.3 形状与密度

半径 `4 / 6 / 8px` 三档；控件高度 `22 / 26 / 30px` 三档；
顶部命令栏 44px、状态栏 28px、卡片头 38px、侧栏条目 28px。
卡片层级靠「表面提亮 + 细描边 + 微阴影」三者叠加，不依赖单根亮线。

### 2.4 基础组件层（L1）

`apps/desktop/src/components/ui/` 提供 Button / IconButton / Input / Select /
Checkbox / FormField / DataRow / Collapsible / NavItem / NavGroup / ErrorBar / EmptyState
与内联 SVG 图标集。样式全部走 `styles/layout.css` 的令牌，组件内不写死颜色。

### 2.5 修订记录

- 2026-10：按参考界面（现代开发者工具深色主题）重做色阶。M0 版把「深色」
  做成了接近纯黑（面板 `#181D25` 与应用底色 `#101318` 明度差仅 4%），整屏
  糊成一块、看不出层级。本版先定中性色阶再挂语义色，语义色色相保持不变，
  以免破坏声谱图色阶与通道配色的既有对应关系。

## 3. 主窗口布局

- 顶部命令栏：导入、采集控制、布局、导出。
- 左侧资源栏：文件、设备、任务、历史记录。
- 中央画布：波形、频谱、声谱图、电平表、指标。
- 右侧检查器：当前分析器的参数和显示选项。
- 底部状态栏：采样率、设备状态、任务进度、丢帧、错误。
- 面板可隐藏、调整大小；优先支持常用布局。

## 4. 视图组件

状态见每行末尾。未实现的保持禁用入口并标里程碑，不做「看起来能用」的假控件。

| 组件 | 内容 | 状态 |
|---|---|---|
| `WaveformView` | 包络、分道/叠加、量级自适应时间轴 | ✅ 已实现（时间缩放与选区待补） |
| `SpectrumView` | 频率/幅值轴、填充/曲线两种形态、峰值标记、游标、缩放 | ✅ 已实现 |
| `SpectrogramView` | ImageData 纹理、inferno 色阶、dB 色阶条、时间与频率轴 | ✅ 已实现（视口分块待补） |
| `LevelMeter` | 逐声道 Peak 条 + 整体 RMS 标记 + 超量程警示 | ✅ 已实现 |
| `ChannelCompareView` | 通道叠加与差异 | ◐ 叠加已并入 `WaveformView`；差异视图待补 |
| `AnalysisSummaryView` | 指标、单位、参数、数据质量诊断 | ◐ 已并入检查器（信号指标 / 参数 / 文件 / 关于） |
| `ChartToolbar` | 缩放、平移、复位、截图、单位选择 | ◐ 缩放/平移/复位已有；截图与单位选择待补 |

### 4.1 显示选项（持久化）

检查器「显示」分区提供，写入 `localStorage`（`auralis.display.v1`）：

- **频谱形态**：填充（面积）/ 曲线（声线）。密集频谱上看细节时用曲线，
  填充会把 -100 dB 以下的区域染色。
- **dB 量程**：全量程 −140…0 / 常用 −100…0 / 细节 −80…−10 / 底噪 −140…−40。
  量程同时作用于频谱、声谱图色阶与电平表，三处不会互相矛盾。
- **声道显示**：分道 / 叠加。叠加用于看两声道差异与相位问题。

单位选择（dBFS ↔ 线性幅值）**没有实现**：dB→线性属于音频换算，
按 ADR-018 规则 1 必须在 Rust 侧完成，不能在前端算；要做就得让 Rust
同时返回线性值，属于后续里程碑。

## 5. 图表性能

- `egui_plot` 用于基础二维曲线原型。
- 密集声谱图不得将每个时频单元建成独立绘图对象。
- 波形应使用 min/max 多级包络。
- 根据像素宽度对频谱数据降采样。
- UI 只读不可变快照；避免持有实时可变缓冲区锁。
- 控制纹理尺寸、缓存容量和刷新频率。

## 6. 交互规范

- 鼠标悬停显示明确数值与单位。
- 游标位置、选区和缩放行为可预测。
- 参数修改应有即时反馈，耗时计算异步运行。
- 对设备不可用、缓冲溢出、无效参数提供可操作提示。
- 常用操作提供键盘支持。
- 支持窗口缩放与高 DPI。

### 6.1 文件任务

- 三种入口，行为一致：顶栏「打开文件…」、侧栏主操作、**拖放文件到窗口**。
- 文件列表里的条目可点击重新分析，不必再过一遍文件对话框。
- 长任务可取消：任务号由前端分配并在发起分析时传给 Rust，运行中可用
  状态栏的「取消」或 `Esc` 中止。取消**不是错误**，保留上一次结果并提示。
- 失败时在画布上方显示错误条，带「重试」（`Ctrl+R`）与「关闭」。

### 6.2 键盘

| 快捷键 | 动作 |
|---|---|
| `Ctrl+O` | 打开文件 |
| `Esc` | 取消正在进行的分析 |
| `Ctrl+R` | 重试上一次文件 |
| 拖拽框选 / 滚轮 / 双击 | 频谱缩放、以光标为中心缩放、复位 |
| `Shift` + 拖拽 | 平移频谱视口 |

## 7. 视觉验收

- 在常规窗口和高 DPI 下无关键控件遮挡。
- 标签、刻度、单位清晰可读。
- 频谱坐标映射与实际数据一致。
- 大文件和实时采集时交互不被计算阻塞。
- 暂停、无信号、错误和削波状态均有明确视觉反馈。
