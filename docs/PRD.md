# 产品需求文档（PRD）

- 产品：Auralis Studio
- 文档版本：1.0
- 状态：开发基线，指标与工期为待验证目标
- 首发平台：Windows 10/11（具体最低版本需在发布前确定）
- 目标形态：本地优先的原生桌面应用

## 1. 产品愿景

提供统一的本地文件与实时输入音频分析工作台，以专业、可信、流畅的可视化体验为核心，支持时域、频域、时频域和基础信号质量分析。

## 2. 目标用户

1. 音频软件与设备开发者：检查信号、频谱和通道问题。
2. 录音及音乐制作人员：查看波形、电平、峰值和频率分布。
3. 测试工程师：执行可复现的信号分析并导出数据。
4. 研究与学习用户：观察时域、频域、时频域特征。

V1 不定位为 DAW、音频修复工具、校准级声学测量系统或法证取证系统。

## 3. 产品原则

- 可视化优先，但所有图表必须来自明确、可测试的数据定义。
- 本地优先；未经用户主动操作，不上传音频。
- 参数、单位和算法定义可追溯。
- 长文件分块处理，实时数据使用有界缓冲。
- 先实现可靠的垂直切片，再扩展功能。

## 4. 版本范围

### V1.0（首发）

- 深色工作台、可调整面板与主题 Token。
- 导入 WAV；经兼容性验证后增加 FLAC、MP3、AIFF 等格式。
- 文件元数据：采样率、声道数、时长、样本帧数、编码信息（可获取时）。
- 波形概览与缩放、时间游标。
- FFT 频谱：窗函数、FFT 长度、线性/对数频率轴、幅值显示、峰值标记。
- 基础指标：Peak、RMS、DC Offset、数字超量程与削波特征提示。
- 实时输入：设备枚举、启动/停止、通道电平与频谱。
- STFT 声谱图及可配置色阶。
- 分析任务进度、取消、错误提示。
- CSV/JSON 导出，配置和最近任务持久化。
- Windows 打包与用户手册。

### V1.5（高级分析）

- SNR、THD、THD+N、频率响应。
- 频段能量与声道对比。
- 更完善的批量分析和报告导出。
- LUFS 与 A/C/Z 计权仅在算法规范、滤波器与验证完成后纳入。
- PDF 报告、分析结果比较。

### V2.0（扩展）

- macOS/Linux。
- 校准工作流和外部测量设备适配。
- 稳定的脚本或插件扩展点。
- 高级项目管理。

## 5. 功能需求

### FR-01 工作台

- 左侧：文件、输入设备、分析任务、历史结果。
- 中央：波形、频谱、声谱图、电平表和指标视图。
- 右侧：当前视图参数检查器。
- 顶部：导入、实时采集控制、布局、导出。
- 底部：采样率、设备状态、任务进度、丢帧与错误提示。
- 面板可隐藏、调整大小；布局在应用重启后恢复。

### FR-02 文件导入

- 支持文件选择器与拖放。
- 先探测元数据，再按块解码。
- 对损坏、截断、空文件和不支持格式提供明确错误。
  截断文件按 ADR-021 处理：**照常分析并标记**（结果只覆盖实际存在的那部分），
  而不是整体报错——「文件没下完」是可恢复的常见状态。
- 大文件不能强制一次性读入内存。
- 取消任务后停止后续解码与分析。

### FR-03 波形

- 显示全局概览和局部时间范围。
- 支持缩放、平移、时间游标和声道切换。
- 长文件使用多级 min/max 波形包络，不向 UI 发送完整 PCM。

### FR-04 FFT 频谱

- 可配置 FFT 长度、Hop Size 和窗函数。
- 支持线性/对数频率轴。
- 明确显示幅值单位与参考值。
- 支持峰值标记、频率/幅值游标和左右声道显示。
- 参数变更后显示所用配置，禁止无提示混合不同配置的结果。

### FR-05 声谱图

- 使用 STFT，支持帧长、Hop Size、窗函数和动态范围设置。
- 支持线性/对数频率轴与色阶调整。
- 使用纹理或等效高效绘制路径。
- 支持长文件分块加载和视口裁剪。

### FR-06 实时输入

- 枚举设备、查询支持的输入配置。
- 启动、停止、设备错误提示。
- 回调中不执行阻塞操作、文件 I/O、UI 操作或无界分配。
- 有界缓冲溢出需可观测，并采取明确策略。
- UI 刷新与音频回调频率解耦。

### FR-07 指标

- Peak：样本绝对值最大值。
- RMS：明确统计窗口、通道与聚合方式。
- DC Offset：每通道平均值。
- 超量程检测与削波特征检测分开呈现。
- SNR/THD/THD+N/LUFS 不得以未经验证的占位数字呈现。

### FR-08 导出与可追溯性

- 导出 CSV 和 JSON。
- 记录分析参数、单位、软件版本、算法版本和输入元数据。
- 对不能可靠计算的指标返回原因，不伪造精确结果。

## 6. 非功能需求

- 稳定性：异常文件不能导致整个应用崩溃。
- 性能：UI 不受离线分析阻塞；实时路径有界。
- 可测试性：DSP 算法可脱离 UI 运行。
- 隐私：默认本地处理。
- 可维护性：模块边界清晰，依赖可追溯。
- 可访问性：文本对比度充分，重要状态不只依靠颜色表达。

## 7. 首版验收

- 可导入约定支持范围内的音频文件。
- 可显示元数据、波形、频谱与声谱图。
- 可进行实时输入分析。
- Peak/RMS/DC Offset 有确定性数值测试。
- 可取消任务并处理错误。
- CSV/JSON 导出可复现必要参数。
- Windows Release 构建和安装流程可重复。
- 性能指标通过明确硬件基线验证。

## 8. 产品边界

Auralis Studio V1 不保证校准级 SPL 测量，不将数字满刻度推断为模拟削波，不以普通 RMS 代替 LUFS，也不对未通过测试的音频格式做兼容性承诺。
